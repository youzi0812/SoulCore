# SoulCore 魂核 · 使用指南（1.8.0 终极版）

魂核是一个让 NPC 拥有「灵魂」的团结引擎插件：人格、情绪、记忆、关系、决策、行为树，以及人格涌现（经历塑造人格）。它不是行为树的替代品，而是**行为树之上的灵魂层**——决定 NPC「是谁」和「想做什么」。

---

## 📦 安装

1. 团结引擎菜单：**资源 → 导入包 → 自定义包** → 选择 `SoulCore_1.8.0.unitypackage`
2. 等待导入完成（Console 无报错即成功）
3. 菜单栏出现 **魂核** 菜单

## 🚀 快速开始（3 步）

1. **创建世界节点**：场景新建空物体 → 添加组件 → **魂核 → World（世界节点）**（负责事件传播/存档/每日循环）
2. **创建 NPC**：新建球体（带碰撞体）→ 添加组件 → **魂核 → NPC（单个角色）**
   - 填 `魂核 ID`（唯一标识）和 `显示名`
   - 挂载一个配置资产（见下）
3. **Play**：点击 NPC 即可打开对话窗口（需在配置资产里开启 LLM 并填接口）

## 🎬 演示场景（Demo）

导入后打开 `Assets/com.soulcore.kernel/Runtime/Unity/Demo/Scenes/SoulDemo.unity`：

- 3 个 NPC：**铁匠老周**（勇敢嘴硬）、**渔夫阿福**（沉默坚韧）、**药师小荷**（温暖共情）
- 白膜村庄（房子/摊位/水井）+ 立绘 + 情绪光环
- 点击任意 NPC 对话，体验人格差异（同样"有人落水"，三人反应不同）

## 🧠 配置资产详解（右键 → 创建 → 魂核 → NPC 配置）

### ⚡ 极简
- **一句话人格**：写一句描述（如"沉默寡言的铁匠，嘴硬心软"）→ 点面板 **🤖 用 LLM 解析一句话人格** → 自动生成 21 特质（也可用本地关键词兜底，无需 LLM）
- **人格预设**：内置预设（默认/勇者/谨慎等）
- **自动多样化**：同一预设下多个 NPC 也略有差异

### 🧠 人格（21 特质）
温暖/共情/信任/乐观/勇气/好奇/创造力/坚韧/理性/耐心/诚实/忠诚/正义感/直觉/抗压/活力/自私/恐惧倾向/易怒/悲伤倾向/希望感——每个滑条悬停有中文释义

### ❤️ 情绪
初始情绪 + 每日衰减系数（情绪会随时间自然回落）

### 💾 记忆
容量上限、初始记忆（可预置世界背景）

### 🎯 决策
四维权重（人格/情绪/记忆/资源）+ **决策情境配置**：自定义「情境 → 动作」映射（不改引擎就能扩 NPC 行为库）

### 💞 关系
初始关系（与其他 NPC 的亲密度/信任/敬畏）

### 🌱 人格涌现（1.8.0 核心）
- **经历塑造人格**：NPC 的近期经历（记忆的情绪标签）每天微调人格——被激怒多了会变易怒，被善待多了会变温暖
- **阈值缓动校准**：反复被背叛 → 信任特质缓动下降（更难信任）——"缓动 + 可关"，区别于纯随机漂移
- 验证：菜单 **魂核 → 人格涌现自测**（12 愤怒 + 3 背叛 → Console 看特质变化）

### 🔌 LLM 入口
- 开启后 NPC 可真实对话（OpenAI 兼容接口：DeepSeek / Kimi / MiniMax 等）
- 默认模型 `deepseek-v4-flash`（快且便宜），可改 `deepseek-v4-pro`（更强）

### 🎛️ 模块开关
按需关闭模块（省算力）：人格/情绪/记忆/决策/关系/兴趣/好奇/情绪感染/风味/梦境

## 🌳 行为树（专属，1.8.0）

菜单 **魂核 → 创建演示行为树** 或手动创建：

- 根节点：**Selector**（依次尝试子节点）
- **条件节点**：TraitCondition（特质阈值）/ EmotionCondition（情绪状态）/ RelationshipCondition（关系值）/ MemoryCondition（记忆检索）/ DecisionCondition（决策动作）/ GoalCondition（当前目标匹配）/ CooldownCondition（冷却）
- **动作节点**：Action（执行意图）/ EmotionShift（情绪变化）/ RelationshipShift（关系变化）/ MemoryStore（存记忆）/ **LlmNarration**（LLM 生成台词，低频 60 秒间隔）
- 行为树输出「意图」（如 go_rescue）→ 游戏侧接收 `OnBehaviorIntent` 执行实际行为

> 提示：行为树资产在 Inspector 中展开层级查看；**注意：嵌套层数请勿超过 10 层**——Unity 序列化器对自引用类型的深度限制为 10（Console 会出现 `Serialization depth limit 10 exceeded` 提示，这是 Unity 对自引用 List 的固有检测，3 层左右的常规树不受影响，但超过 10 层的深层节点会保存不完整）。

## ⚔️ 决策调试

菜单 **魂核 → 决策调试面板**：选中 NPC → 触发情境 → 看四维评分柱子（人格/情绪/记忆/资源），调参从盲人摸象变所见即所得。

## 🧪 AI 测 AI 仿真

菜单 **魂核 → AI 仿真：决策分布**：5 人格 × 6 情境 × 20 次批量跑，Console 看决策分布是否符合设计（改决策引擎后跑一次防回归）。

## ❓ 常见问题

- **对话显示"LLM 调用失败"**：检查配置资产的 LLM 区（启用 + 接口地址 + Key + 模型名）；DeepSeek 旧模型名 `deepseek-chat` 已失效，请用 `deepseek-v4-flash` / `deepseek-v4-pro`
- **NPC 点了没反应**：确认 NPC 物体有碰撞体 + 组件已挂载 + Play 状态
- **Console 没有日志**：Console 窗口选「全部」过滤；NPC 组件可调 `secondsPerGameDay`（秒=1 天，默认 300）
- **人格涌现没变化**：看 Console 的 `[SoulCore] 人格涌现` 日志（每日重置时输出）；配置资产是静态模板，运行时灵魂才会变
- **存档在哪**：World 节点自动存档（可在组件上改存档名/间隔）
