SoulCore 魂核 1.4.0 — 免费体验版
================================

本文件夹内容
------------
SoulCore_1.4.0_Import.unitypackage   ← Unity 导入包（约 7 MB）

安装
----
1. Unity / 团结：Assets → Import Package → Custom Package
2. 选择本目录下的 SoulCore_1.4.0_Import.unitypackage → 全选 Import
3. 打开：Assets/SoulCore/Demos/StoreDemo/Scenes/SoulCore_VillageDemo_Cube.unity
4. Play

完整版 1.6.0 见商店（归田镇 Demo + 世界事件 + 存档）。
