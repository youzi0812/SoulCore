# 魂核 SoulCore · 意识流 NPC 内核（免费版 1.8.0）

> 让 NPC 拥有人格、情绪、记忆和自主决策的团结引擎 / Unity 内核。
> 本仓库为**免费版（1.8.0，核心完整）**。2.0 付费版已在团结引擎商店上架，差异见下方对比表。

## 这是什么

魂核不是 if-else 对话树，也不是传统状态机。它是一套"由内向外"驱动的 NPC 意识内核：

- **人格引擎**：21 项特质三层分类（必填 8 / 情境 7 / 个性 6），支持预设库，也支持**一句话生成完整人格**（SoulGenerator）
- **情绪引擎**：15 种情绪 VAD 模型，衰减 + 主导情绪 + 事件驱动更新
- **记忆引擎**：三层记忆桶（短期 / 长期 / 永久）+ 重要性权重 + **语义检索** + 召回强化 + 遗忘淘汰。NPC 不会转身就忘
- **决策引擎**：多维加权评分 + 情境映射 + 关键词触发层 + **八级决策优先级** + 种子确定性（同输入同输出，存档可复现）
- **关系引擎**：亲密度 / 信任 / 欠债三通道 + 每日结算
- **自主行为**：完整动机引擎（能量 / 好奇 / 守护）+ **专属行为树 SoulBehaviorTree** + 人格涌现（经历塑造人格）
- **世界系统**：JSON 版本化存档 + 双模式事件传播（立即 / 延迟）+ 谣言系统 + 自指涉系统
- **LLM 对话**：开放性 LLM 客户端 + 运行时对话 UI，功能性对话可接大模型
- **模块开关**：SoulModuleFlags 按模块裁剪，不用的功能零开销

## 快速开始

环境：团结引擎 / Unity 2022.3+

两种方式任选：

1. **直接用源码**：把本仓库 `Assets/` 下的内容拷进你的工程
2. **用 unitypackage**：下载仓库根目录的 `SoulCore_1.8.0.unitypackage`，导入工程

使用文档见 `Assets/com.soulcore.kernel/Docs/SoulCore使用指南.md`。

给一个 NPC 挂魂核：Inspector 里填身份 + 选人格预设，10 秒跑起来。

## 适用场景

- 剧情 / 解谜游戏：NPC 有秘密、有立场，会随关系释放信息
- 模拟经营 / 生活模拟：村民自主行动、互相传播事件
- 社交推理（狼人杀、骗子酒馆类）：撒谎和隐瞒有内部成本核算，行为逻辑连贯
- 任何"希望 NPC 不像 NPC"的项目
