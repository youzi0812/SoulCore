# SoulCore 魂核 — 团结引擎 AI-NPC 灵魂插件

魂核让 NPC 拥有「灵魂」：人格、情绪、记忆、关系、决策、专属行为树，以及**人格涌现**（经历塑造人格）。它不是行为树的替代品，而是**行为树之上的灵魂层**——决定 NPC「是谁」和「想做什么」。

## 📦 安装

1. 下载 `1.7.0/SoulCore_1.7.0.unitypackage`
2. 团结引擎菜单：**资源 → 导入包 → 自定义包** → 选择文件
3. 导入后见 `Assets/com.soulcore.kernel/Docs/SoulCore使用指南.md`（完整攻略）

## 🚀 快速开始

1. 场景空物体 → **添加组件 → 魂核 → World（世界节点）**
2. 新建球体（带碰撞体）→ **添加组件 → 魂核 → NPC（单个角色）** → 填魂核 ID/显示名
3. 右键 → **创建 → 魂核 → NPC 配置** → 写一句话人格 → 挂到 NPC
4. **Play** → 点击 NPC 对话（1.8.0：配置资产 LLM 区填接口；1.7.0：无对话）

## 🧠 一句话生成人格

配置资产填 `沉默寡言的铁匠，嘴硬心软`：
- 1.8.0：面板 **🤖 用 LLM 解析一句话人格** → 自动生成 21 特质（DeepSeek 等任意 OpenAI 兼容接口）
- 1.7.0：本地关键词兜底（12 组）直接解析

## 🌱 人格涌现（1.8.0）

NPC 的近期经历每天微调人格：被激怒多了会变易怒、被背叛多了会变多疑（阈值缓动校准）。验证：菜单 **魂核 → 人格涌现自测**。
